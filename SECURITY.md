# Politique de sécurité

Ce dépôt est un travail pratique pédagogique : un service local, en lecture
seule, sans données personnelles ni authentification. Il n'est déployé nulle
part.

## Signaler une vulnérabilité

Utiliser le signalement privé de GitHub (onglet *Security* → *Report a
vulnerability*). Ne pas ouvrir de ticket public.

Un signalement utile contient : ce qui est affecté, comment le reproduire, ce
qu'un attaquant obtient, et la version testée.

## Engagement

Aucun délai n'est promis : le projet n'est pas maintenu au-delà de la durée du
module. Un délai annoncé et non tenu vaut moins que pas de délai.
